# Catalogue de cours

Le launcher `cem_importer.py run` contient volontairement une liste prédéfinie des dépôts de cours connus du département d'informatique du CÉM.

Il n'est donc pas nécessaire de copier/coller des URLs GitHub ou de maintenir une configuration par cours.

Le catalogue actuel contient :

- `1P6` — `departement-info-cem/1P6`
- `2P6` — `departement-info-cem/2P6`
- `3M5` — `departement-info-cem/3M5-Intro-Mobile`
- `3S4` — `departement-info-cem/3s4-cybersec`
- `3U4` — `departement-info-cem/3U4-cybersec`
- `3W6` — `departement-info-cem/3W6-Web-Transactionelle`
- `4D5` — `departement-info-cem/4D5-Base-De-Donnees-Et-Prog-Web`
- `4W6` — `departement-info-cem/4W6-WebServices`
- `5N6` — `departement-info-cem/5N6-mobile-2`
- `5W5` — `departement-info-cem/5W5-Web-Avancee`
- `420-4A4` — `departement-info-cem/420-4A4`
- `420-SN1` — `departement-info-cem/420-SN1`
- `Z03` — `departement-info-cem/z03`

Pour ajouter un nouveau dépôt officiel, ajoutez une entrée à `COURSES` dans `cem_importer.py`, puis ajoutez ou adaptez les tests de conversion si le cours introduit de nouveaux composants MDX.
